# gh-pr-formatter ロゴコンセプト案

## コンセプト

`gh-pr-formatter` のロゴは、ツールの処理フローを 1 つのシンボルに圧縮することを狙います。

- **左右に分岐した線**: 複数の Pull Request
- **中央への収束**: Author ごとのグルーピング
- **下向きのドキュメント形状**: Markdown への整形出力
- **小さなチェックマーク**: 「マージ済み PR を安全に集約する」信頼感

## 形の意味づけ

1. 上部の 2 本線は `develop` と `main` の流れを抽象化。
2. 線が中央のノードで合流し、PR が「整理される」瞬間を表現。
3. 下部のシートは生成される `release_YYYYMM_HHmm.md` を表現。
4. シート内の水平線は Markdown のテキストブロックを示す。

## カラーパレット（提案）

- **Primary**: `#2563EB`（信頼感のある blue）
- **Accent**: `#7C3AED`（整形・変換を示す violet）
- **Success**: `#16A34A`（マージ済み/完了）
- **Neutral**: `#111827`（文字色）

## トーン

- 「開発者ツールらしい」幾何学ベース
- 複雑にしすぎず、CLI ツールらしい実用性を重視
- アイコン単体でも認識できるシルエット

## 利用ガイド（簡易）

- 最小表示サイズ: **24px**
- 推奨余白: ロゴ外形の **10%**
- 背景が濃い場合はシート部分を白にしてコントラストを確保
